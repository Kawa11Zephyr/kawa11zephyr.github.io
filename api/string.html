String и java.lang

Самый используемый класс Java

Неизменяемость и пул строк

String неизменяем (immutable): ни один метод не правит существующую строку — все возвращают новую. Строковые литералы кэшируются в пуле строк (string pool) — одинаковые литералы указывают на один объект.

java
String s = "Java";
s.concat(" 21");                 // возвратит "Java 21", но s НЕ изменится!
s = s.concat(" 21");             // теперь s = "Java 21"

String a = "hello";              // из пула
String b = "hello";              // тот же объект из пула
String c = new String("hello");  // НОВЫЙ объект в куче
a == b;        // true   (одна ссылка)
a == c;        // false  (разные объекты)
a.equals(c);   // true   (одинаковое содержимое)
a.intern() == c.intern();  // true — интернирование возвращает строку из пула

Форматирование

java
String name = "Java"; int version = 21; double pi = 3.14159;

// printf-стиль
String s1 = String.format("%s %d — %.2f", name, version, pi);   // Java 21 — 3.14
String s2 = "%s %d".formatted(name, version);                   // то же, JDK 15+
System.out.printf("Версия: %d, сборка %s%n", version, "LTS");

// Полезные флаги: %5d (ширина), %05d (нули), %,d (1 000 000), %-10s (влево)

StringBuilder: когда строк много

Конкатенация в цикле создаёт O(n²) промежуточных объектов. Для склеек используйте StringBuilder:

java
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i).append(',');      // append, insert, delete, reverse...
}
String result = sb.toString();

// Но разовая конкатенация — это нормально, компилятор сам сделает StringBuilder:
String ok = name + " " + version;  // не оптимизируйте вручную

Preview JDK 21: String Templates

java
// --enable-preview: интерполяция выражений прямо в строке
String name = "мир";
String greeting = STR."Привет, \{name}! 2+2 = \{2 + 2}";
String padded = STR."%8s".formatted(name);   // можно совмещать
⚠️ Внимание
String Templates были сняты с рассмотрения в JDK 23 для переработки дизайна — в продакшене используйте formatted()/String.format. Пример приведён для понимания истории preview-возможностей JDK 21.

Регулярные выражения

java
boolean ok = "java21@jdk.dev".matches("[\\w.]+@[\\w.]+");   // быстрый разовый матч

Pattern p = Pattern.compile("(\\d{4})-(\\d{2})-(\\d{2})"); // компилируем один раз
Matcher m = p.matcher("Дата: 2023-09-19, релиз JDK 21");
if (m.find()) {
    m.group(0);   // 2023-09-19
    m.group(1);   // 2023
}
String cleaned = "a1b2c3".replaceAll("\\d", "#");   // a#b#c#
