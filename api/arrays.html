Массивы и java.util.Arrays

Фиксированные структуры данных и утилиты для них

Создание и инициализация

java
int[] numbers = new int[5];              // 5 нулей (значения по умолчанию)
int[] primes = {2, 3, 5, 7, 11};         // инициализация литералом
int[] also = new int[]{2, 3, 5};         // полная форма
String[] words = new String[3];          // [null, null, null] — ссылочный тип!

numbers.length;                          // 5 — длина (без скобок, это поле!)
primes[0];                               // 2 — доступ по индексу
primes[4] = 13;                          // изменение элемента
// primes[5] = 1;                        // ArrayIndexOutOfBoundsException

Обход

java
// 1. Классический for — когда нужен индекс
for (int i = 0; i < numbers.length; i++) {
    numbers[i] *= 2;
}

// 2. for-each — когда индекс не нужен
for (int n : primes) System.out.print(n + " ");

// 3. Stream — функциональный стиль
int sum = Arrays.stream(primes).sum();               // 28
String csv = Arrays.stream(words)
                   .filter(Objects::nonNull)
                   .collect(Collectors.joining(", "));

Многомерные массивы

java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
};
matrix[1][2];                    // 6

int[][] ragged = new int[3][];   // «рваный» массив: строки разной длины
ragged[0] = new int[1];
ragged[1] = new int[2];
ragged[2] = new int[3];

// Обход матрицы
for (int[] row : matrix) {
    for (int cell : row) System.out.printf("%3d", cell);
    System.out.println();
}

Утилиты java.util.Arrays

МетодЧто делает
Arrays.toString(a)Читаемое представление [1, 2, 3] (для 2D — deepToString)
Arrays.sort(a)Сортировка in-place: примитивы — dual-pivot quicksort O(n log n), объекты — TimSort (стабильная)
Arrays.sort(a, cmp)Сортировка с компаратором
Arrays.binarySearch(a, key)Бинарный поиск в отсортированном массиве; иначе результат не определён
Arrays.copyOf(a, newLen)Копия новой длины (обрезка/расширение нулями)
Arrays.copyOfRange(a, from, to)Копия диапазона
Arrays.fill(a, value)Заполнить значением
Arrays.equals(a, b)Попарное сравнение (deepEquals для вложенных)
Arrays.asList(...)Список-представление массива фиксированного размера (устаревший стиль; лучше List.of)
Arrays.stream(a)Поток элементов (IntStream для int[])
Arrays.parallelSort(a)Параллельная сортировка для больших массивов
Arrays.mismatch(a, b)Индекс первого различия, −1 если равны (JDK 9)
java
int[] data = {5, 1, 4, 2, 8};

Arrays.sort(data);                       // [1, 2, 4, 5, 8]
int idx = Arrays.binarySearch(data, 4);  // 2
System.out.println(Arrays.toString(data));

Integer[] boxed = {5, 1, 4};
Arrays.sort(boxed, Comparator.reverseOrder());   // [5, 4, 1] — только для объектов!

int[] copy = Arrays.copyOf(data, 10);    // дополнен нулями до длины 10
⚠️ Внимание
Arrays.sort(int[]) сортирует по возрастанию без компаратора — примитивы нельзя «развернуть». Обходные пути: сортировать Integer[] с Comparator.reverseOrder(), или отсортировать по возрастанию и обойти с конца.

Массив vs ArrayList

Критерийint[] / String[]ArrayList
РазмерФиксированныйРастёт динамически
ПримитивыДа, без упаковкиТолько обёртки (Integer)
Скорость доступаМаксимальнаяПочти такая же
УдобствоМало операцийadd, remove, contains, stream…
Когда братьИзвестен размер, критична производительность, примитивы, JNIПочти всегда в бизнес-коде
📘 Примечание
Массивы ковариантны (String[] можно присвоить Object[] — с риском ArrayStoreException в рантайме), а дженерики инвариантны (List<String> ≠ List<Object> — ошибка компиляции). Это одна из причин предпочитать дженерик-коллекции массивам в современном коде.
