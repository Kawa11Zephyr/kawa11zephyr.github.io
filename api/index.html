Стандартная библиотека JDK: какие пакеты за что отвечают

Стандартная библиотека Java (модуль java.base и другие модули JDK) содержит более 6000 классов. Полная официальная документация — Java SE 21 API Specification. Здесь собраны самые востребованные пакеты с примерами.

Как читать Javadoc

Сгенерировать документацию локально можно командой javadoc. Структура страницы класса стандартна: иерархия наследования → объявление класса → конструкторы → методы (с модификаторами, параметрами, возвращаемым типом) → унаследованные методы.

bash
# Документация собственного проекта:
javadoc -encoding UTF-8 -charset UTF-8 -d docs -sourcepath src com.example

# Посмотреть документацию класса в консоли (если IDE не под рукой):
jshell
jshell> /doc java.util.stream.Stream

Шпаргалка: java.time (дата и время)

Старые Date/Calendar признаны неудачными — используйте java.time (JSR-310):

java
LocalDate today = LocalDate.now();                     // 2026-10-23
LocalDate d = LocalDate.of(2026, 1, 15);
d.plusDays(30).minusMonths(1);                         // иммутабельно: каждый вызов — новый объект

LocalDateTime meeting = LocalDateTime.of(2026, 10, 30, 18, 30);
ZonedDateTime tokyo = meeting.atZone(ZoneId.of("Europe/Moscow"))
                             .withZoneSameInstant(ZoneId.of("Asia/Tokyo"));

Duration  wait  = Duration.ofMinutes(90);              // «машиночитаемое» время
Period   age   = Period.between(LocalDate.of(2000,5,1), today);  // «человеческое»
age.getYears();

String iso = today.format(DateTimeFormatter.ISO_LOCAL_DATE);      // 2026-10-23
String rus = today.format(DateTimeFormatter.ofPattern("dd.MM.yyyy")); // 23.10.2026
LocalDate parsed = LocalDate.parse("15.01.2026",
        DateTimeFormatter.ofPattern("dd.MM.yyyy"));

Instant epoch = Instant.now();                          // метка времени (UTC) для логов
📘 Примечание
Все классы java.time неизменяемы и потокобезопасны. Храните моменты времени в Instant, «человеческие» даты — в LocalDate/ZonedDateTime.
