Примеры программ

Два законченных проекта от простого к продвинутому

Примеры написаны на чистом JDK 21 без сторонних зависимостей — их можно скопировать, скомпилировать и запустить сразу после установки JDK.

🏦
Пример 1. Банковские счета
Консольное приложение: классы и record, коллекции Map/List, исключения, switch-меню, Stream API. Закрепляет руководства 1–4.
🌐
Пример 2. HTTP-сервер на JDK 21
JSON API без единой зависимости: встроенный HttpServer + виртуальные потоки + java.net.http клиент для теста.

Как запускать примеры

bash
# Однофайловый пример — просто:
java BankApp.java

# Многофайловый проект:
javac -encoding UTF-8 -d out src/*.java
java -cp out BankApp
