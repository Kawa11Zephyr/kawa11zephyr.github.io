Часто задаваемые вопросы

Короткие ответы на самые частые вопросы

Java и JavaScript — это одно и то же?

Нет. Это два совершенно разных языка: Java — компилируемый в байткод, статически типизированный, запускается на JVM; JavaScript — динамический язык для веба, исполняется движками браузеров и Node.js. Схожесть названий — результат маркетинга 1995 года.

Java бесплатна?

Сам язык и OpenJDK — полностью открыты (GPLv2 + Classpath Exception). Бесплатные production-сборки: Eclipse Temurin (Adoptium), Amazon Corretto, Azul Zulu Community, BellSoft Liberica Community, Microsoft Build of OpenJDK. Oracle JDK 21+ также бесплатен для большинства сценариев по лицензии NFTC, но для крупных компаний при длительном использовании старых версий есть нюансы — читайте лицензию.

Какой JDK скачать?

Для учёбы и большинства проектов — Eclipse Temurin 21 с adoptium.net. См. инструкцию по установке.

Что такое LTS и зачем он нужен?

Long-Term Support — версия, которая получает обновления безопасности много лет (для Temurin 21 — до 2028+). В продакшене используют LTS (8, 11, 17, 21, 25), между ними — экспериментируют с полугодовыми релизами.

Нужна ли IDE, чтобы писать на Java?

Нет: достаточно блокнота и JDK. Компилируем javac Hello.java, запускаем java Hello, а с JDK 11 можно вообще без компиляции: java Hello.java. REPL jshell идеален для экспериментов. Но для крупных проектов IDE (IntelliJ IDEA Community — бесплатна) сильно экономит время.

Правда, что Java медленная?

Миф из 2000-х. Современная JVM с JIT-компиляцией (C2/Graal) и AOT-кэшами (CDS, Leyden) показывает производительность на уровне C++ в долгих серверных нагрузках. А JDK 21 с виртуальными потоками резко увеличил пропускную способность I/O-приложений.

Java живая или «умирает»?

Java — один из самых используемых языков (TIOBE: стабильно топ-3–4). Полугодовой релизный цикл с 2018 года вернул языку динамику: лямбды (8), модули (9), записи (16), sealed (17), виртуальные потоки (21). Экосистема (Spring, Kafka, Android-бэкенд, Gradle/Maven) огромна.

Что такое «байткод»?

Промежуточное представление программы (файлы .class), которое понимает JVM. Один и тот же байткод исполняется на Windows, Linux, macOS и даже на микросхемах с JVM. См. «Первые шаги».

Сколько памяти нужно JVM?

Для hello world — десятки мегабайт. Настройки: -Xms (начальная куча), -Xmx (максимальная куча), например java -Xmx512m -jar app.jar. В контейнерах JVM сама определяет доступную память (UseContainerSupport).

Как быстро выучить Java?

Базовый синтаксис — 2–4 недели регулярной практики; уверенное ООП + коллекции + Stream API — 3–6 месяцев. Порядок изучения по этому справочнику: первые шаги → синтаксис → ООП → коллекции → Stream API → практика.
