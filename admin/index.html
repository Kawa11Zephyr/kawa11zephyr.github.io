Панель администратора (учебная)

⚠️ Внимание
⛔ Это учебная страница для лабораторных работ 3.1 и 3.4 «Защита от кибератак». Она имитирует админ-панель, которую в реальной жизни нужно защищать правилами WAF. Никаких настоящих данных и функций здесь нет.

Если вы видите эту страницу — значит правило Cloudflare WAF «Блокировка админки» выключено или вы зашли с доверенного IP. После включения правила запросы к /admin/ должны отбиваться с кодом 403 Forbidden ещё на границе сети (Edge), не доходя до Origin-сервера.

Форма входа (имитация)

Форма никуда не отправляет данные. Она нужна, чтобы демонстрировать Rate Limiting: нажмите «Войти» несколько раз и посмотрите срабатывание правила в Cloudflare.

Как это используется в лабораторных

  1. ЛР 3.1, шаг 2 — правило WAF: URI Path contains "/admin" → действие Block. Проверка: curl -I https://ВАШ-ДОМЕН/admin/ должен вернуть 403.
  2. ЛР 3.4, часть 2 — правило «Защита админки по IP»: доступ разрешён только доверенным IP, остальные получают 403.
  3. ЛР 3.4, часть 3 — Rate Limiting на POST-запросы к этой странице (имитация защиты от брутфорса).
  4. Security → Events — все срабатывания правил видны в журнале событий Cloudflare.
