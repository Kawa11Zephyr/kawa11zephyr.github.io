История версий Java

От Java 1.0 (1996) до современных полугодовых релизов

До 2017 года Java выходила крупными релизами раз в 2–4 года. Начиная с JDK 10 Oracle перешла на календарный цикл: новая версия каждые 6 месяцев (март и сентябрь). Каждые два года (по чётным сентябрьским релизам, начиная с 21) выбирается LTS-версия с многолетней поддержкой.

📘 Примечание
⭐ LTS (Long-Term Support) — версии с расширенной поддержкой: 8, 11, 17, 21, 25. Промежуточные релизы получают обновления безопасности только до выхода следующей версии.

Какую версию ставить в 2026 году

  • Новые проекты — JDK 21 или 25 (оба LTS). Данный справочник описывает 21 как самую распространённую LTS-версию в проде.
  • Учебные курсы — JDK 21: стабильные виртуальные потоки и паттерны, огромное количество библиотек уже совместимо.
  • Легаси — если проект на 8/11, миграция на 21 даёт максимум выгоды (производительность + LTS-поддержка до 2030-х).

Схема нумерации

Начиная с Java 9 номер версии имеет формат FEATURE.INTERIM.UPDATE (например, 21.0.2). Флаг --release 21 при компиляции гарантирует, что код не использует API более новых версий:

bash
javac --release 21 -d out src/com/example/Main.java
java --version
# openjdk 21.0.2 2024-01-16 LTS
