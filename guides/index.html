Руководства по Java

Пять руководств от синтаксиса до виртуальных потоков

Руководства расположены в порядке изучения. Каждое содержит теорию, примеры кода и подводные камни.

🔤
1. Основы синтаксиса
Типы данных, переменные, операторы, условия, циклы, switch с сопоставлением типов.
🏛️
2. Объектно-ориентированное программирование
Классы и объекты, инкапсуляция, наследование, полиморфизм, интерфейсы, record и sealed.
🗃️
3. Коллекции
List, Set, Map, Queue: выбор структуры, сложность операций, Sequenced Collections из JDK 21.
🌊
4. Лямбды и Stream API
Функциональный стиль: лямбда-выражения, ссылки на методы, потоки данных, коллекторы.
🧵
5. Виртуальные потоки (JDK 21)
Лёгкие потоки Project Loom: миллионы одновременных задач, executor, подводные камни.
