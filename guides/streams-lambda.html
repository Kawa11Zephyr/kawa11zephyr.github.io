Лямбды и Stream API

Функциональный стиль: лямбды, ссылки на методы и потоки данных

Лямбда-выражения

Лямбда (JDK 8) — сокращённая запись реализации функционального интерфейса (интерфейса с единственным абстрактным методом):

java
// Было (анонимный класс):
Runnable old = new Runnable() {
    @Override public void run() { System.out.println("work"); }
};

// Стало (лямбда):
Runnable r = () -> System.out.println("work");
Comparator<String> byLength = (a, b) -> a.length() - b.length();
java.util.function.IntUnaryOperator square = x -> x * x;

Главные функциональные интерфейсы (java.util.function)

ИнтерфейсСигнатураСмыслПример
Function<T,R>R apply(T t)ПреобразованиеString::length
Predicate<T>boolean test(T t)Проверка условияs -> s.isEmpty()
Consumer<T>void accept(T t)Действие-«потребление»System.out::println
Supplier<T>T get()Поставщик значения() -> new ArrayList<>()
UnaryOperator<T>T apply(T t)Преобразование T→Ts -> s.trim()
BiFunction<T,U,R>R apply(T t, U u)Два аргументаMap::merge

Ссылки на методы

java
// Четыре вида ссылок:
Function<String, Integer> f1 = String::length;        // статический/instance метод класса
Consumer<String>        f2 = System.out::println;     // метод конкретного объекта
Supplier<List<String>>  f3 = ArrayList::new;          // конструктор (List::of, etc.)
Function<String, String> f4 = s -> s.trim();          // = String::trim

Stream API: конвейер обработки данных

Поток (stream) — ленивый конвейер: источник → промежуточные операции (0..n) → терминальная операция. Данные не хранятся в потоке — они проходят через него один раз.

java
List<String> names = List.of("Анна", "Борис", "Алиса", "Виктор", "Агата");

List<String> result = names.stream()          // источник
    .filter(n -> n.startsWith("А"))           // промежуточная: отбор
    .map(String::toUpperCase)                 // промежуточная: преобразование
    .sorted()                                 // промежуточная: сортировка
    .toList();                                // терминальная: сбор в List (JDK 16+)
// [АГАТА, АЛИСА, АННА]

Источники потоков

java
List.of(1, 2, 3).stream();                  // из коллекции
Arrays.stream(new int[]{1, 2, 3});          // из массива
Stream.of("a", "b");                        // из значений
IntStream.range(0, 10);                     // 0..9
IntStream.rangeClosed(1, 100).sum();        // 1..100 → 5050
Stream.iterate(1, n -> n * 2).limit(8);     // бесконечный: 1,2,4,...,128
Stream.generate(Math::random).limit(3);     // бесконечный генератор
Files.lines(Path.of("data.txt"));           // построчно из файла (не забыть close!)
"строка".chars();                           // коды символов (IntStream)

Сборка результатов: Collectors

java
import static java.util.stream.Collectors.*;

record Employee(String dept, String name, int salary) {}
List<Employee> staff = List.of(
    new Employee("IT", "Анна", 150_000),
    new Employee("IT", "Борис", 120_000),
    new Employee("HR", "Вера", 90_000));

// Группировка: Map<String, List<Employee>>
Map<String, List<Employee>> byDept = staff.stream()
    .collect(groupingBy(Employee::dept));

// Среднее по группе: Map<String, Double>
Map<String, Double> avgSalary = staff.stream()
    .collect(groupingBy(Employee::dept, averagingInt(Employee::salary)));

// В одну строку через запятую
String names = staff.stream().map(Employee::name).collect(joining(", "));

// Сумма, partitioning (на 2 группы по предикату)
int total = staff.stream().mapToInt(Employee::salary).sum();
Map<Boolean, List<Employee>> rich = staff.stream()
    .collect(partitioningBy(e -> e.salary() > 100_000));

Практический пример

java
// Топ-3 города по населению из списка стран, начинающихся на «K»
record Country(String name, String city, long population) {}

List<Country> countries = /* ... */ List.of();

List<String> top3 = countries.stream()
    .filter(c -> c.name().startsWith("K"))
    .sorted(Comparator.comparingLong(Country::population).reversed())
    .limit(3)
    .map(Country::city)
    .toList();

Параллельные потоки

java
long count = hugeList.parallelStream()
    .filter(this::isPrimeCandidate)
    .count();          // работа распределяется по ядрам CPU (ForkJoinPool.commonPool)
⚠️ Внимание
parallelStream() ускоряет только тяжёлые CPU-задачи на больших объёмах (сотни тысяч элементов). Для лёгких операций или I/O параллелизм даст замедление из-за накладных расходов. Для I/O-нагрузок в JDK 21 используйте виртуальные потоки.
📘 Примечание
Поток можно использовать один раз: после терминальной операции повторный вызов бросит IllegalStateException. Ленивость: промежуточные операции не выполняются до терминальной.
