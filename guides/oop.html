Объектно-ориентированное программирование

Классы, объекты и три кита ООП — плюс современные record и sealed

Классы и объекты

Класс — чертёж (описание полей и методов), объект — экземпляр класса в памяти. Конструктор инициализирует объект; new выделяет память в куче.

java
public class Cat {
    // Поля (состояние)
    private final String name;
    private int age;

    // Конструктор
    public Cat(String name, int age) {
        this.name = name;   // this — ссылка на текущий объект
        this.age = age;
    }

    // Метод (поведение)
    public void meow() {
        System.out.println(name + " говорит: мяу!");
    }

    public int getAge() { return age; }

    public static void main(String[] args) {
        Cat barsik = new Cat("Барсик", 3);  // создание объекта
        barsik.meow();                       // Барсик говорит: мяу!
    }
}

Инкапсуляция

Поля скрываются за модификатором private, доступ — через геттеры/сеттеры. Это защищает инварианты объекта (нельзя задать бессмысленное состояние):

java
public class BankAccount {
    private double balance;   // никто не изменит баланс напрямую

    public void deposit(double amount) {
        if (amount <= 0) throw new IllegalArgumentException("Сумма должна быть > 0");
        balance += amount;
    }

    public double getBalance() { return balance; }
}

Наследование

Ключевое слово extends создаёт подкласс. Java поддерживает одиночное наследование классов (один родитель), но множественное наследование интерфейсов.

java
public class Animal {
    protected String name;

    public Animal(String name) { this.name = name; }

    public void makeSound() { System.out.println("Какой-то звук"); }
}

public class Dog extends Animal {
    public Dog(String name) {
        super(name);              // вызов конструктора родителя — первая строка
    }

    @Override                      // аннотация: проверка переопределения компилятором
    public void makeSound() {
        System.out.println(name + ": Гав!");
    }
}

Полиморфизм

Ссылка типа родителя может указывать на объект потомка; вызванный метод определяется реальным типом объекта (динамическая диспетчеризация):

java
List<Animal> animals = List.of(new Dog("Бобик"), new Cat("Мурка"));
for (Animal a : animals) {
    a.makeSound();   // для Dog напечатает «Гав!», для Cat — «Мяу!»
}

Интерфейсы

Интерфейс — контракт: «что умеет», без состояния. С JDK 8 интерфейсы могут содержать default- и static-методы с реализацией:

java
public interface Flyable {
    int MAX_ALTITUDE = 12_000;        // неявно public static final

    void fly();                        // неявно public abstract

    default void land() {              // реализация по умолчанию (JDK 8+)
        System.out.println("Плавное приземление");
    }

    static Flyable of(String type) {   // статический метод интерфейса
        return () -> System.out.println("Летит " + type);
    }
}

public class Drone implements Flyable {
    @Override
    public void fly() { System.out.println("Дрон взлетает"); }
}

Записи (record) — JDK 16+

record — компактный неизменяемый класс-«переносчик данных»: конструктор, геттеры, equals, hashCode и toString генерируются автоматически.

java
public record Point(int x, int y) {
    // Компактный конструктор — валидация без boilerplate:
    public Point {
        if (x < 0 || y < 0) throw new IllegalArgumentException("Отрицательные координаты");
    }
}

var p = new Point(3, 4);
p.x();               // 3 — геттеры без префикса get
p.toString();        // Point[x=3, y=4]
new Point(3, 4).equals(p);   // true — сравнение по значениям

Запечатанные классы (sealed) — JDK 17+

sealed ограничивает список наследников — вместе с switch из JDK 21 это даёт исчерпывающую алгебраическую типизацию:

java
public sealed interface Shape permits Circle, Rectangle, Triangle {}

public record Circle(double radius) implements Shape {}
public record Rectangle(double w, double h) implements Shape {}
public record Triangle(double a, double b, double c) implements Shape {}

// switch знает ВСЕ возможные типы — default не нужен!
double area = switch (shape) {
    case Circle c       -> Math.PI * c.radius() * c.radius();
    case Rectangle r    -> r.w() * r.h();
    case Triangle t     -> {
        double s = (t.a() + t.b() + t.c()) / 2;   // формула Герона
        yield Math.sqrt(s * (s - t.a()) * (s - t.b()) * (s - t.c()));
    }
};
💡 Совет
Связка record + sealed + switch-паттерны — современный идиоматический стиль Java (иногда называют «алгебраическими типами данных»). Компилятор сам проверит, что вы обработали все случаи.

Статические члены и вложенные классы

java
public class Config {
    private static Config instance;              // одно общее поле на класс
    public static final String VERSION = "21";   // константа

    public static Config getInstance() {         // singleton
        if (instance == null) instance = new Config();
        return instance;
    }

    // Статический вложенный класс — не держит ссылку на внешний объект
    public static class Builder {
        public Builder port(int p) { /* ... */ return this; }
        public Config build() { return new Config(); }
    }
}
📘 Примечание
Внутренние (inner, нестатические) классы хранят скрытую ссылку на внешний объект — частая причина утечек памяти в GUI/Android. Предпочитайте static вложенные классы, если внешний контекст не нужен.
