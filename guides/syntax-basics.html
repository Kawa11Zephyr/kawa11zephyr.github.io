Типы, переменные, операторы, ветвления и циклы

Примитивные типы

В Java восемь примитивных типов — они хранят значение напрямую (в стеке или в полях объекта), а не ссылку:

ТипРазмерДиапазон / значенияПример
byte8 бит−128 … 127byte b = 100;
short16 бит−32 768 … 32 767short s = 30_000;
int32 бита−2³¹ … 2³¹−1 (~2.1 млрд)int i = 42;
long64 бита−2⁶³ … 2⁶³−1long l = 9_000_000_000L;
float32 бита~7 значащих цифрfloat f = 1.5f;
double64 бита~15–17 значащих цифрdouble d = 3.14159;
char16 битСимвол UTF-16char c = 'Я';
boolean1 бит*true / falseboolean ok = true;
📘 Примечание
Все остальные типы — ссылочные: классы (включая String), интерфейсы, массивы, перечисления, записи. Переменная ссылочного типа хранит ссылку на объект в куче (heap) или null.

Переменные и var

java
final double PI = 3.14159;      // константа: final + ЗАГЛАВНЫЕ_БУКВЫ
int counter = 0;                 // обычная локальная переменная
var list = new ArrayList<String>(); // var (с JDK 10): тип выводится компилятором
                                    // здесь list имеет тип ArrayList<String>

var — не «динамическая типизация»: тип определяется один раз при инициализации и больше не меняется. Java остаётся строго статически типизированным языком.

Операторы

java
// Арифметические
int sum = 7 / 2;        // 3   — целочисленное деление!
double exact = 7 / 2.0; // 3.5
int rem = 7 % 2;        // 1   — остаток от деления

// Сравнение и логика
boolean ok = (sum > 2) && (rem == 1);   // && — «ленивое» И
boolean alt = ok || sum < 0;            // || — «ленивое» ИЛИ
boolean neg = !ok;

// Строки: только equals(), НЕ ==!
String a = "text";
String b = new String("text");
System.out.println(a == b);      // false — разные объекты
System.out.println(a.equals(b)); // true  — одинаковое содержимое

// Строки сцепляются через +
String greeting = "Привет, " + "мир!".repeat(2); // Привет, мир!мир!
⚠️ Внимание
Классическая ошибка новичка — сравнение строк через ==. Оператор == сравнивает ссылки, а не содержимое. Для строк всегда используйте equals().

Условия: if / else

java
int score = 87;
if (score >= 90) {
    System.out.println("Отлично");
} else if (score >= 70) {
    System.out.println("Хорошо");
} else {
    System.out.println("Нужно подтянуть");
}

// Тернарный оператор
String verdict = score >= 60 ? "сдал" : "не сдал";

// instanceof с паттерном (финал с JDK 16): приведение не нужно
Object obj = "строка";
if (obj instanceof String s && s.length() > 3) {
    System.out.println("Длинная строка: " + s);
}

switch: от классики к JDK 21

java
// Современный switch-выражение (с JDK 14): стрелки, без break, возвращает значение
String name = "Java";
int released = switch (name) {
    case "Java"    -> 1996;
    case "Kotlin"  -> 2016;
    case "Scala"   -> 2004;
    default        -> 0;
};

// JDK 21: сопоставление с образцом по ТИПУ + guard-условия when
Object value = 42;
String result = switch (value) {
    case Integer i when i > 100 -> "большое число";
    case Integer i              -> "число " + i;
    case String s               -> "строка " + s;
    case int[] arr              -> "массив из " + arr.length;
    case null                   -> "null (JDK 21 умеет и так!)";
    default                     -> "неизвестно";
};

Циклы

java
// for — когда известно число итераций
for (int i = 0; i < 5; i++) {
    System.out.print(i + " ");        // 0 1 2 3 4
}

// for-each — обход коллекции/массива
for (String lang : List.of("Java", "Kotlin")) {
    System.out.println(lang);
}

// while — условие проверяется до итерации
int n = 10;
while (n > 0) n /= 2;

// do-while — минимум одна итерация гарантирована
do {
    n++;
} while (n < 5);

// break / continue / метки
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == j) continue outer;  // следующая итерация внешнего цикла
        if (i * j > 2) break outer;  // выход из обоих циклов
    }
}
💡 Совет
Современная Java часто заменяет явные циклы на Stream API — декларативные цепочки filter/map/collect. См. руководство по лямбдам и потокам.
