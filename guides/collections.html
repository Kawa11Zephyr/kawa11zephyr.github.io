Коллекции

List, Set, Map и Queue: что выбирать и как использовать

Collections Framework (пакет java.util) — набор интерфейсов и реализаций для хранения групп объектов. Интерфейс Collection охватывает списки, множества и очереди; Map (ключ→значение) стоит особняком, но относится к тому же фреймворку.

Карта интерфейсов

ИнтерфейсЧто описываетПопулярные реализации
ListУпорядоченный список, дубликаты разрешены, доступ по индексуArrayList, LinkedList
SetМножество без дубликатовHashSet, LinkedHashSet, TreeSet
Queue / DequeОчередь / двусторонняя очередьArrayDeque, PriorityQueue
MapПары «ключ → значение», ключи уникальныHashMap, LinkedHashMap, TreeMap

List: ArrayList и LinkedList

java
List<String> names = new ArrayList<>();     // интерфейс слева, реализация справа
names.add("Анна");
names.add("Борис");
names.add(0, "Алиса");          // вставка по индексу
names.set(1, "Анна-Мария");     // замена
names.remove("Борис");          // удаление по объекту
names.get(0);                   // Алиса
names.size();                   // 2
names.contains("Анна-Мария");   // true

// Неизменяемый список (JDK 9+)
List<String> frozen = List.of("раз", "два", "три");
// frozen.add("четыре");        // UnsupportedOperationException!

// Копия любого Collection в неизменяемый List (JDK 16+)
List<String> copy = names.stream().toList();

Сложность операций

get(i) / set(i, v)O(1)O(n)
add(v) (в конец)O(1) амортизированноO(1)

💡 Совет
В 95% случаев выбирайте ArrayList — он быстрее даже для вставок благодаря кэш-локальности памяти. LinkedList почти не нужен; для стека/очереди используйте ArrayDeque.

Set: множество без дубликатов

java
Set<String> unique = new HashSet<>(List.of("a", "b", "a", "c"));
System.out.println(unique);            // [a, b, c] — дубликат исчез, порядок не гарантирован

// LinkedHashSet — хранит порядок вставки
Set<Integer> ordered = new LinkedHashSet<>(List.of(3, 1, 2));  // [3, 1, 2]

// TreeSet — сортированный набор, O(log n)
Set<String> sorted = new TreeSet<>(Set.of("banana", "apple")); // [apple, banana]

// Классика: удалить дубликаты из списка
List<Integer> deduped = new ArrayList<>(new LinkedHashSet<>(numbers));

Map: словарь ключ→значение

java
Map<String, Integer> ages = new HashMap<>();
ages.put("Анна", 25);
ages.put("Борис", 30);
ages.put("Анна", 26);                    // перезапись значения

ages.get("Анна");                        // 26
ages.getOrDefault("Виктор", -1);         // -1 (ключа нет)
ages.containsKey("Борис");               // true
ages.merge("Виктор", 40, Integer::sum);  // добавить или просуммировать
ages.remove("Борис");

// Обход всеми способами:
for (Map.Entry<String, Integer> e : ages.entrySet()) {
    System.out.println(e.getKey() + " → " + e.getValue());
}
ages.forEach((name, age) -> System.out.println(name + ": " + age));

// Инициализация литералом (до 10 пар, JDK 9+)
Map<String, Integer> small = Map.of("a", 1, "b", 2);

LinkedHashMapВставки или доступа (LRU!)O(1)Нужен порядок вставки
TreeMapСортировка ключейO(log n)Нужны диапазоны subMap/headMap

Queue и Deque

java
Deque<String> stack = new ArrayDeque<>();  // стек: LIFO
stack.push("a"); stack.push("b");
stack.pop();                                // b

Deque<String> queue = new ArrayDeque<>();  // очередь: FIFO

Sequenced Collections — новинка JDK 21

До JDK 21 у коллекций не было единого способа взять «первый» и «последний» элемент. Новые интерфейсы SequencedCollection, SequencedSet, SequencedMap (JEP 431) добавляют единые методы всем упорядоченным структурам:

java
// Все реализации List/Set/Deque теперь умеют:
SequencedCollection<String> seq = new LinkedHashSet<>();
seq.add("B"); seq.add("A"); seq.add("C");

seq.addFirst("X");          // X, B, A, C
seq.addLast("Z");           // X, B, A, C, Z
seq.getFirst();             // X  (вместо iterator().next())
seq.getLast();              // Z  (вместо list.get(list.size()-1))
seq.removeFirst();
var backwards = seq.reversed();   // Z, C, A, B — «перевёрнутое» представление

// У Map появились sequenced-представления:
LinkedHashMap<String, Integer> map = new LinkedHashMap<>();
map.put("k1", 1); map.put("k2", 2);
map.sequencedKeySet().getFirst();       // k1
map.sequencedEntrySet().getLast();      // k2=2
map.firstEntry();                       // (по LinkedHashMap)
📘 Примечание
reversed() не копирует данные — это «вид» коллекции. Изменения исходной коллекции отражаются в перевёрнутом виде и наоборот.

Дженерики и коллекции

java
List<Number> numbers = List.of(1, 2.5, 3L);       // список чисел разных типов
List<? extends Number> upper = numbers;            // wildcard: «какие-то Number»
void printAll(List<?> any) { any.forEach(System.out::println); }

Map<String, List<String>> grouped = new HashMap<>();
grouped.computeIfAbsent("fruits", k -> new ArrayList<>()).add("apple");
⚠️ Внимание
Итераторы «быстрого отказа» (fail-fast): изменение коллекции во время обхода в цикле for-each бросает ConcurrentModificationException. Удаляйте через iterator.remove() или removeIf().
