Настройка окружения

JAVA_HOME, PATH, инструменты JDK и выбор IDE

Переменные окружения

JAVA_HOME — путь к корню установленного JDK. Её требуют сборочные системы (Maven, Gradle) и многие IDE. PATH должен содержать %JAVA_HOME%\bin (Windows) или $JAVA_HOME/bin (Linux/macOS).

Windows (PowerShell от имени администратора)

powershell
# Узнать, где лежит JDK после установки winget/MSI:
Get-ChildItem 'C:\Program Files\Eclipse Adoptium'

# Задать JAVA_HOME навсегда (путь подставьте свой):
[Environment]::SetEnvironmentVariable('JAVA_HOME',
  'C:\Program Files\Eclipse Adoptium\jdk-21.0.5.11-hotspot', 'Machine')

# Открыть новое окно терминала и проверить:
echo $env:JAVA_HOME
java -version

Linux / macOS (~/.bashrc или ~/.zshrc)

bash
# Добавить в конец файла ~/.bashrc:
export JAVA_HOME=$(dirname $(dirname $(readlink -f $(which java))))
export PATH="$JAVA_HOME/bin:$PATH"

# Применить и проверить:
source ~/.bashrc
echo $JAVA_HOME      # например, /home/user/.sdkman/candidates/java/current
java -version

Настройка IntelliJ IDEA (кратко)

  1. Скачайте IntelliJ IDEA Community с jetbrains.com и установите.
  2. New Project → язык Java → в поле *JDK* выберите установленный JDK 21 (или *Download JDK… → Eclipse Temurin 21*).
  3. Создайте файл Main.java в папке src, напишите код и нажмите зелёный ▶ (или Shift+F10).

Структура простого проекта без IDE

text
myproject/
├── src/                 # исходный код (.java)
│   └── com/example/
│       └── Main.java
├── out/                 # скомпилированные классы (.class) — не коммитим в git
└── lib/                 # сторонние jar-библиотеки (если есть)
bash
# Компиляция всех исходников в папку out с кодировкой UTF-8:
javac -encoding UTF-8 -d out $(find src -name '*.java')

# Запуск (класс с package com.example):
java -cp out com.example.Main
📘 Примечание
Для серьёзных проектов используйте сборочные системы Maven или Gradle — они управляют зависимостями и сборкой автоматически. Это тема отдельного руководства, здесь мы работаем «вручную», чтобы понять механику.
