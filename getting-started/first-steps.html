Первая программа

Hello World: от исходного кода до запуска

Пишем Hello World

Создайте файл Hello.java. Имя файла обязано совпадать с именем публичного класса:

java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Привет, Java 21!");
    }
}

Компилируем и запускаем

bash
# 1. Компиляция: javac создаёт файл байткода Hello.class
$ javac Hello.java

# 2. Запуск: java исполняет байткод на JVM (без расширения .class!)
$ java Hello
Привет, Java 21!

Что происходит под капотом

  1. javac проверяет синтаксис и типы, генерирует байткод — Hello.class.
  2. java запускает JVM; загрузчик классов (ClassLoader) читает .class в память.
  3. Верификатор проверяет байткод на безопасность.
  4. Интерпретатор начинает построчное исполнение; «горячие» участки кода JIT-компилятор (C2) переводит в машинный код на лету.
  5. Сборщик мусора (GC) автоматически освобождает память ненужных объектов.

Однофайловый режим (с JDK 11)

Для небольших скриптов компиляцию можно пропустить — java сам скомпилирует файл в памяти:

bash
$ java Hello.java
Привет, Java 21!

REPL: jshell

jshell — интерактивная консоль Java (появилась в JDK 9). Идеальна, чтобы попробовать API без создания файлов:

console
$ jshell
jshell> var langs = java.util.List.of("Java", "Kotlin", "Scala")
langs ==> [Java, Kotlin, Scala]

jshell> langs.stream().map(String::toUpperCase).toList()
$2 ==> [JAVA, KOTLIN, SCALA]

jshell> /exit

Разбор метода main

ЭлементЗначение
publicМетод доступен извне — JVM вызывает его как точку входа
staticМетод принадлежит классу, а не объекту: экземпляр создавать не нужно
voidНичего не возвращает
mainЗарезервированное имя точки входа (можно изменить при запуске: java -cp out MyMainClass)
String[] argsАргументы командной строки: java Hello раз два → args = ["раз", "два"]

Preview в JDK 21: ещё короче

JEP 445 (preview) разрешает писать учебные программы вообще без объявления класса и static:

java
// Файл HelloPreview.java — preview-возможность JDK 21
void main() {
    IO.println("Привет из будущего Java!");
}
bash
$ javac --release 21 --enable-preview HelloPreview.java
$ java --enable-preview HelloPreview
Привет из будущего Java!
⚠️ Внимание
Preview-возможности нельзя использовать в продакшене: их синтаксис может измениться. В финальном виде «compact source files» появились в JDK 25.
